## 🏗️ Featured Project — Personal Security Homelab

> A self-contained, enterprise-grade security lab running on an HP EliteBook 840 G3.
> Built from scratch. Every config researched, broken, and fixed by me.

**What's running:**

| Component | Technology |
|:---|:---|
| Hypervisor | Proxmox VE 9.1.1 (bare metal) |
| Firewall / Gateway | pfSense CE 2.7.2 |
| IDS / IPS | Suricata (inline IPS mode) |
| VPN | WireGuard (remote access) |
| Network Design | Dual Linux bridge — full traffic inspection enforced |
| SIEM | Wazuh *(in deployment)* |
| Attack Platform | Kali Linux *(planned)* |

**The architecture in one sentence:**
All lab VM traffic is forced through pfSense before reaching the internet — no exceptions, no bypasses.
